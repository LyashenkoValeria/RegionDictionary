# Словарь регионов — REST-приложение

Учебный проект. Серверная часть приложения для справочника регионов.

---

## О проекте

Словарь регионов — учебное приложение, представляющее собой REST API для управления справочником регионов. Приложение позволяет хранить, просматривать и изменять информацию о регионах.

---

## Функциональность

- Получение списка всех регионов
- Поиск региона по идентификатору
- Создание нового региона
- Редактирование существующего региона
- Удаление региона

---

## Запуск

- Клонировать проект
- Собрать образ и запустить через docker-compose up --build

---

## Технологии

- **Язык:** Java
- **Фреймворк:** Spring Boot
- **База данных:** PostgreSQL
- **Миграции:** Liquibase
- **Тестирование:** JUnit, Postman
- **Документация API:** Swagger (OpenAPI)
- **Контейнеризация:** Docker Compose
